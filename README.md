# RougGame

2D 像素风肉鸽游戏，基于 Python 3.x + Pygame-CE 开发。

## 快速开始

```bash
pip install -r requirements.txt
python main.py
```

## 操作

| 按键 | 功能 |
|------|------|
| WASD | 移动 |
| 鼠标 | 瞄准 + 左键攻击 |
| E | 开门 / 交互 |
| I | 背包 |
| ESC | 暂停菜单 |

## 玩法概述

- **房间探索**：每阶段包含6个随机生成的房间，通过不同类型的门串联
- **门系统**：挑战门（高强度/技能奖励）、消耗门（低强度/技能奖励）、谜题门（小型谜题/大量资源）
- **局内成长**：击杀怪物获得经验升级，选择 HP / 攻速 / 移速 / 技能等级等强化
- **场外存储**：稀有装备通过 JSON 持久化，可在后续对局中使用
- **难度递增**：每通过一个阶段，怪物强度翻倍，奖励同步强化

## 项目结构

```
rouggame/
├── main.py              # 游戏入口
├── assets/
│   ├── configs/         # 平衡性、装备、仓库等 JSON 配置
│   ├── sprites/         # 精灵图片资源
│   └── sounds/          # 音效资源
├── src/
│   ├── core/            # 引擎、状态机、事件总线、摄像机、等距变换
│   ├── ecs/             # ECS 框架（Entity、Component、System、World）
│   │   └── components/  # 各类组件定义
│   ├── systems/         # 系统实现（AI、战斗、碰撞、渲染、粒子等）
│   ├── entities/        # 实体工厂（玩家、敌人、子弹、掉落物）
│   ├── world/           # 地图系统（房间生成、地图管理、瓦片）
│   ├── scenes/          # 场景（主菜单、游戏中、背包、GameOver、转场等）
│   ├── graphics/        # 精灵图集
│   ├── audio/           # 音频管理
│   ├── data/            # 数据存取（装备、仓库）
│   └── ui/              # UI 组件（血条、经验条、小地图、按钮等）
└── tools/
    ├── config_editor.py       # 终端配置工具
    ├── config_editor_gui.py   # GUI 配置工具入口
    └── gui_editor/            # GUI 配置工具实现
```

## 配置工具

支持通过可视化界面或终端调整游戏参数：

```bash
# GUI 编辑器
python -m tools.config_editor_gui

# 终端编辑器
python -m tools.config_editor
```

## 技术架构

- **ECS 架构**：Entity-Component-System，支持灵活组合游戏对象行为
- **场景状态机**：管理主菜单、游戏内、背包、转场等不同场景的切换
- **JSON 驱动配置**：怪物属性、门规则、掉落表、阶段参数等均通过 JSON 配置
- **程序化精灵生成**：运行时生成像素风精灵，同时支持自定义 PNG 资源
